# Robot Reference Generation Benchmark

本 benchmark 收录 RobotInteraction 机器人参考资产 prompt 文件的前 10 条，ID 为 robot_000001–robot_000010。任务是纯文生图（T2I），没有输入参考图；用于选择生成机器人身份参考图的模型。

- 英文 prompt 与源文件逐字一致；同时提供前述中文译文，可在平台切换语言。
- 8 条真实摄影风格、2 条非真实风格（第 5 条复古动漫、第 8 条漫画）。
- 所有样本采用同一种双足体态，头部、躯干、手部、配色和呈现风格不同。它们是用户指定的首 10 条试跑，不代表全部 5,000 条的形态覆盖。
- 统一分辨率为 1024×1024，样本 seed 为 42–51；不同模型使用相同 prompt、尺寸和对应 seed。
- manifest 基准步数为 28；蒸馏/加速模型采用自身规定的采样计划，并在实际运行记录中注明，不把不同步数结果当成严格等算力比较。
- 每模型每样本先生成一张，比较主体完整性、头躯干形状、双臂及手指数、无遮挡、中性姿态、材质配色、风格遵从性和图像质量。单 seed 结果仅为探索性检查。
- 输出由平台正常归档到 `output/gen/{pipeline}/robot_reference_generation/`，可在结果对比页按样本 ID 对齐。

源文件路径与 SHA-256 保存在每个样本的 extra 中。本文件夹仅加入 benchmark，不修改源 prompt 数据。
